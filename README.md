# Teacher Management System

Tech Stack: Python, Tkinter, SQL

---

## Overview
A desktop application built with **Python Tkinter** to manage student and teacher data efficiently.  
Supports user authentication (login/signup), student CRUD operations, and exporting data to CSV.

---

## Features
- Login & Signup system with MySQL authentication
- Add, update, delete, and view student records
- Search and sort student records
- Export student data to CSV
- Display current date and time
- User-friendly GUI with images and themes
- Database integration with MySQL
